# Assignment 3: Neural Networks

Official handout: [EECS 498/598 Winter 2022 Assignment 3](https://web.eecs.umich.edu/~justincj/teaching/eecs498/WI2022/assignment3.html)

This directory keeps the official Jupyter notebooks and starter layout together
with completed modular neural-network implementations.

## Implemented

### Fully connected networks

- Linear and ReLU forward/backward layers
- Two-layer and arbitrary-depth fully connected classifiers
- Inverted dropout
- SGD with momentum, RMSProp, and Adam
- Solver configurations and overfitting hyperparameters

### Convolutional networks

- Naive convolution and max-pooling forward/backward layers
- Three-layer convolutional network
- VGG-style deep convolutional network
- Kaiming initialization
- Batch normalization and spatial batch normalization
- Optional batch-normalized convolutional blocks
- CIFAR-10 solver configuration

## Use with JupyterLab

Start JupyterLab from this directory so the notebooks can import the adjacent
Python files:

```powershell
cd assignments\a3-neural-networks
jupyter lab
```

Open `fully_connected_networks.ipynb` first, followed by
`convolutional_networks.ipynb`. On a local machine, skip the notebook's
Google Drive mounting and Colab setup cells; the starter files already have
the correct relative layout here.

The notebooks are the intended interactive interface. The implementations live
in the two Python files, so edits made there are immediately available after
rerunning an import/reload cell.

## Validation

From the repository root:

```powershell
python -m pytest tests\test_assignment3.py
```

The data-free tests cover numerical gradients for Linear, ReLU, fully connected
models, naive convolution, max pooling, BatchNorm, and SpatialBatchNorm. They
also test dropout, optimizer updates, Kaiming initialization, and integration
of the three-layer and deep convolutional models.

The official CIFAR-10 accuracy experiments and four trained `.pth` artifacts
are not checked into this repository. They must be generated by running the
notebooks with the course dataset on a CUDA-capable environment; model weights
are ignored by Git.
